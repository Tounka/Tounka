## Sobre mí

Soy desarrollador Full Stack con experiencia en sitios corporativos, e-commerce y sistemas de gestión. Trabajo con React y Next.js para crear interfaces y soluciones web orientadas a las necesidades de cada proyecto.

Inicié mi formación en Ingeniería en Software en la **UAdeO en 2021**. Mi experiencia en gerencia fortaleció mi capacidad de liderazgo, organización y trabajo en equipo; hoy aplico ese aprendizaje al desarrollo de tecnología.

- **iNNCi Lab · enero de 2025–actualidad:** colaboración como prestador de servicios en soluciones web para clientes y colaboradores.
- **Sitio Random · agosto de 2025–agosto de 2026:** desarrollo Full Stack de soluciones web con Next.js.
- **Freelance · actualidad:** sitios de servicios, catálogos de inventario, plataformas de reservas y sistemas internos.
